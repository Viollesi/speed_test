# Проверка скорости скачивания

Консольный скрипт выполняет 10 последовательных загрузок указанного ресурса и
рассчитывает прикладную скорость скачивания.


## Установка и запуск

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone <https://github.com/Viollesi/speed_test.git>
cd <speed_test>
```

Запустите скрипт, передав URL большого файла:

```bash
python speed_checker.py https://example.com/large-image.jpg
```

Справка по аргументам:

```bash
python speed_checker.py --help
```

Пример вывода:

```text
Выполнено запросов: 10
Среднее время запроса: 1.24 с
Скачано данных: 52.80 МБ
Средняя скорость: 34.06 Мбит/с
```

### Проверка через Cloudflare

Для проверки скорости через интернет можно использовать тестовый ресурс
Cloudflare:

```bash
python speed_checker.py "https://speed.cloudflare.com/__down?bytes=10000000"
```

Параметр `bytes=10000000` задаёт размер одного ответа — 10 МБ. Скрипт выполнит
10 запросов и суммарно скачает около 100 МБ. Чтобы сократить расход трафика,
можно указать меньший размер, например `bytes=5000000` — около 50 МБ за весь
тест.

### Проверка через локальный сервер

Для проверки работы скрипта без расходования интернет-трафика создайте
временный файл и запустите HTTP-сервер. На macOS и Linux:

```bash
cd /tmp
python -c "with open('test-speed.bin', 'wb') as file: file.truncate(10_000_000)"
python -m http.server 8000
```

Не останавливая сервер, в другом терминале запустите:

```bash
python speed_checker.py http://localhost:8000/test-speed.bin
```

В журнале локального сервера появятся 10 запросов. Такой запуск проверяет
последовательность запросов, подсчёт данных и формирование результата, но не
измеряет скорость интернет-соединения.

## Тесты

Тесты не обращаются в интернет и запускаются без установки дополнительных
пакетов:

```bash
python -m unittest discover -s tests -v
```

## Методика измерения

Скрипт строго последовательно выполняет 10 HTTP-запросов. Для каждого запроса
таймер учитывает подключение, ожидание ответа и чтение всего тела. Ответ читается
блоками без сохранения на диск; объём определяется по фактически прочитанным
байтам, а не по заголовку `Content-Length`.

Используются десятичные единицы измерения:

```text
среднее время = общее время / количество запросов
объём в МБ = общее количество байтов / 1 000 000
скорость в Мбит/с = общее количество байтов × 8 / общее время / 1 000 000
```

Результат отражает прикладную скорость скачивания с конкретного ресурса, а не полную пропускную способность интернет-канала. На него влияют сервер, CDN, кэширование, задержка, качество Wi-Fi и текущая нагрузка сети. HTTP- и TLS-заголовки, а также другой служебный трафик в скачанный объём не включаются.
